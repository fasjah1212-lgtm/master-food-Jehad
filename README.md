# Master Food — الموقع الرسمي (إعادة تصميم)

موقع بسيط وسريع لـ **مصنع شركة الفوزان للصناعات الغذائية – ماستر فود** (القصيم – بريدة).
HTML / CSS / JS فقط، بدون مكتبات ولا خطوة بناء. عربي (افتراضي) وإنجليزي.

الموقع المنشور: https://fasjah1212-lgtm.github.io/master-food-Jehad/
(يُنشر تلقائيًا عبر `.github/workflows/pages.yml` مع كل رفع على الفرع.)

## ترتيب الصفحة

1. Hero تفاعلي: كوز ذرة في المنتصف فوق خلفية مزرعة ناعمة، وحوله بطاقات المنتجات الخمسة تتغير بالسحب (ماوس) أو Swipe (جوال) أو الأسهم
2. عن Master Food (نص + صورة + زر اعرف المزيد)
3. المنتجات (5 بطاقات، ولكل منتج نافذة تفاصيل برابط مباشر مثل `#glucose-syrup`)
4. لماذا Master Food
5. الجودة (6 خطوات + صورة مختبر)
6. التطبيقات (4 صور كبيرة)
7. صورة كبيرة للمصنع/الصوامع
8. الرؤية والقيم
9. التواصل (أزرار اتصال وبريد، هاتف، بريد، موقع، خريطة)
10. Footer

## قبل الإطلاق — مطلوب من الشركة

- [x] **الشعار الرسمي**: مضاف في `assets/img/logo.webp` (كامل) و `logo-mark.webp` (الدرع فقط) و `favicon.png`.
- [x] **ألوان الهوية**: مأخوذة من الشعار (أحمر `#B71B22` / `#E41F28`، أخضر `#3CA949`، ذهبي `#E9C350`).
- [ ] **الصور**: كل الصور حاليًا صور Stock من Pexels (مجانية الاستخدام) تُحمَّل من `images.pexels.com`.
      استبدلها بصور المصنع الحقيقية: ضع الملفات في `assets/img/` وغيّر روابط `<img>` في `index.html`
      ورقم `img` لكل منتج في `assets/js/main.js`.
- [x] **جنين الذرة**: الوصف والمواصفات والاستخدامات مضافة.
- [x] **جلوتين ميل 60%**: الوصف والمواصفات والاستخدامات مضافة.
- [ ] **الرسالة (Mission)**: لم يُعثر عليها في المصادر المتاحة، فلم تُعرض.
- [ ] **Social Media**: لم يُعثر على حساب رسمي مؤكد، فلا توجد أيقونات.
- [ ] **الخريطة**: تعرض مدينة بريدة؛ ضع إحداثيات المصنع الدقيقة إن رغبت.

## مصدر المحتوى

كل النصوص مأخوذة من صفحات master-food.co الرسمية المفهرسة في محركات البحث، ومن نص الطلب
(الرؤية، القيم، قائمة مهام الجودة). لم تُضف أرقام إنتاج أو شهادات أو عملاء أو إحصائيات؛
الرقم الوحيد المعروض هو «أكثر من 40 عامًا» منذ تأسيس شركة الفوزان للصناعات الغذائية كما ورد في الموقع.

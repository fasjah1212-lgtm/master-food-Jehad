# Master Food — FROM CORN TO FOOD INGREDIENTS

إعادة تصميم الموقع الرسمي لـ **مصنع شركة الفوزان للصناعات الغذائية – ماستر فود** (القصيم – بريدة).
الموقع مبني كرحلة واحدة لحبة الذرة: تبدأ الحبة كمادة خام، ثم تمر بالمعالجة، ثم تصبح عدة منتجات.

## التشغيل

الموقع ثابت (HTML / CSS / JS) بدون أي مكتبات أو خطوة بناء.

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

للنشر: فعّل **GitHub Pages** على هذا الفرع (Settings → Pages → Deploy from branch)، أو ارفع الملفات كما هي إلى أي استضافة ثابتة.

## مصدر المحتوى

الموقع الحالي `master-food.co` كان محجوبًا من بيئة العمل، فجُمع المحتوى من نسخ الصفحات الرسمية المفهرسة في محركات البحث
(`master-food.co/?lang=en`، صفحة نشاء الذرة، صفحة شراب الجلوكوز، صفحة Glutofed 16%، صفحة رؤيتنا، صفحة رقابة الجودة) ومن نص الطلب.
لم تُضف أي أرقام إنتاج أو شهادات أو عملاء أو أسواق أو إحصائيات.

**موثّق من الموقع الرسمي:** اسم المصنع، الشركة الأم وعبارة «تأسست منذ أكثر من 40 عامًا»، إنتاج النشاء والجلوكوز من الذرة الصفراء،
وصف نشاء الذرة، وصف شراب الجلوكوز واستخداماته، وصف Glutofed 16%، نص الجودة، العنوان، أرقام الهاتف، البريد الإلكتروني.

**من نص الطلب (منسوب للموقع الحالي):** الرؤية، القيم السبع، قائمة مهام إدارة الجودة التفصيلية، أهمية إدارة المخازن.

### يحتاج مراجعة قبل الإطلاق

- [ ] **الشعار الرسمي**: الشعار في الموقع رمز مؤقت (حبة ذرة داخل دائرة). استبدله بملف الشعار الأصلي.
- [ ] **ألوان الهوية**: الأخضر `#0e4a35` والذهبي `#e2a414` اختيرا بحسب الطلب. طابقهما مع ألوان الشعار الأصلي في `:root` داخل `styles.css`.
- [ ] **جنين الذرة وجلوتين ميل 60%**: لم يُعثر على وصف رسمي لهما، فالموقع يعرض الاسم مع «التفاصيل عند الطلب». أضف النص الرسمي في `PRODUCTS` داخل `main.js`.
- [ ] **الصور**: كل المرئيات حاليًا SVG/Canvas خفيفة. يمكن إضافة صور المصنع الحقيقية (WebP/AVIF مع `loading="lazy"`).
- [ ] **حسابات التواصل الاجتماعي**: لم يُعثر على حساب رسمي مؤكد، لذلك لا توجد أيقونات Social.
- [ ] **نموذج التواصل**: لا يوجد خادم، فالنموذج يجهّز رسالة بريد إلى `masterfood@ftinco.com`. اربطه بخدمة نماذج عند النشر إن أردت.

## الأداء وإمكانية الوصول

- بدون مكتبات JavaScript، وبدون WebGL. الرسوم SVG وCanvas فقط.
- خطوط Google مع `display=swap` وبدائل نظامية.
- `prefers-reduced-motion`: تتوقف الحركات وتظهر الحالات النهائية الثابتة.
- الوضع الداكن يتبع إعداد النظام.
- لغتان: AR / EN مع حفظ الاختيار محليًا.
